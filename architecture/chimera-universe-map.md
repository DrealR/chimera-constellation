# The CHIMERA Universe Map

CHIMERA is a constellation of bodies with different responsibilities, evidence rules, and time depths. Coherence does not require every repository to repeat the same sentences.

```text
DEJI / CAPTAIN
lived direction, observation, questions, consequence
        ↓
CORE
raw conversations, developmental lineage, metaphysics, corrections
        ↓ classify / test / firewall / preserve provenance
FRAMEWORK
current portable operators, practices, bounded carriers, teaching routes
        ↓ translate and pressure-test
GUTS                         DOMAINS
body · language · math       AI · chess · basketball · music · cooking
                             relationships · crypto · stories
        ↘                    ↙
APPLIED PROJECTS
Field · SPARK · BeyondChess · Guitar Cave · Grove · Honeydew · others
        ↓ lived feedback, failure, capacity, relationship, residue
        └────────────────────────────────────────────────────→ CORE

CONSTELLATION wraps the cycle:
agents · handoffs · routing · publication · memory · operational rhythm
```

## Authority by question

| Question | Primary body |
|----------|--------------|
| What did Deji actually say, and how did the thought change? | **Core** |
| What is the current public, bounded formulation? | **Framework** |
| How should this be expressed through body, language, or formal candidates? | **Guts** |
| What does the lens reveal inside a particular practice? | **Domain repo** |
| Does it survive contact with a real learner, user, relationship, or system? | **Applied project** |
| How is work routed among agents and public surfaces? | **Constellation** |
| Who selects the end, bears the cost, and can refuse? | **The embodied operator at the named scale** |

No domain repo proves the whole framework. No fluent agent response becomes doctrine by circulation. No old “universal truth” label outranks a later counterexample preserved in Core.

## Register flow

```text
source / cosmology
        ↓ classification
carrier / story ←→ operator / mechanism
        ↓               ↓
audience translation   domain validation where required
        └──────→ embodied application
```

Stories may travel publicly when their register and seam are visible. Genesis, One Piece, the Matrix, guitar, and *Meet Dave* are not thrown away; they are kept as human-scale carriers beside grounded claims and explicit limits.

## Snapshot rule

Architecture documents describe intended relations. Runtime claims require observation. Repositories may be current, stale, mirrored, or locally modified. Before changing a satellite:

1. inspect local status;
2. compare with the remote head;
3. preserve unique local artifacts;
4. fast-forward only clean bodies;
5. classify the document's register and era;
6. link rather than copy when the bodies can resolve one another;
7. return consequential findings to Core.

## Healthy circulation

The system breathes when:

- Core never loses the raw path;
- Framework can be taught without requiring the whole archive;
- language adapts to the receiver without changing evidence status;
- domain experts can disagree and improve the model;
- applied work returns counterexamples, not only success stories;
- the constellation serves human direction instead of becoming the hidden host.

The shortest operator test remains: **Who sets the BPM?**
